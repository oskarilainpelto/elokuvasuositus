# Elokuva suositus

- Sovelluksessa käyttäjät pystyvät jakamaan elokuvia ja arvostelemaan niitä. Elokuvasta näytetään sen nimi, julkaisuvuosi, ohjaaja ja lyhyt kuvaus.
- Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
- Käyttäjä pystyy lisäämään elokuvia, sekä muokkaamaan ja poistamaan lisäämiään elokuvia.
- Käyttäjä näkee sovellukseen lisätyt elokuvat
- Käyttäjä pystyy etsimään elokuvia hakusanalla.
- Käyttäjäsivu näyttää, montako elokuvaa käyttäjä on lisännyt ja listan käyttäjän lisäämistä elokuvista.
- Käyttäjä pystyy valitsemaan elokuvalle esimerkiksi seuraavia luokitteluja:
  - Elokuvan genre: toiminta, komedia, draama, kauhu, dokumentti, jännitys
  - Elokuvan ikäraja: S, 7, 12, 16, 18
- Käyttäjä pystyy antamaan elokuvalle kirjallisen arvostelun ja arvosanan asteikolla 1–5. Elokuvan sivulla näytetään käyttäjien arvostelut sekä arvosanojen keskiarvo.

Tässä pääasiallinen tietokohde on elokuva ja toissijainen tietokohde on elokuvan arvostelu.
